## 真实浏览器验收步骤

脚本 `tools/e2e/acceptance.cjs` 用 Playwright 驱动 Edge，每次使用全新数据：

1. 家属登录，大字模式生效
2. 自然语言预约并提交
3. 网格员工作台受理
4. 智能派单，前 3 名和解释，一键派单
5. 护理员今日工单
6. 上门执行：定位偏差须说明、清单、照片、血压、签退
7. 家属查看证据链，低分评价
8. 随访录入高血压，红色预警置顶
9. 二次授权查看敏感信息
10. 快进 31 分钟，红色预警自动升级到街道
11. 预警闭环为已转诊
12. 异常处置队列闭环
13. 账单差异逐条处理和人工复核
14. 网格员核对、机构确认、监管抽查、账单生效
15. 缴费登记回写
16. 回访转投诉、结论
17. 三个看板、四类图表、导出
18. 绩效榜、服务目录、规则
19. 审计日志和哈希链校验
20. 用户、权限矩阵、业务参数、任务
21. 离线同步：断网打开页面、签到、勾选、签退，联网后自动同步并核对服务端状态
22. 备份、校验、两步恢复、核对报告
23. 越权访问管理页被拦回首页

## 测试发现并修复的缺陷

| 缺陷 | 发现方式 | 修复 |
| --- | --- | --- |
| 抽查证据含日期时间对象，写 JSON 列时报 500 | 账单审批测试 | 证据统一转 ISO 字符串 |
| 备份包损坏时，校验接口抛出未捕获的解压异常 | 损坏检测测试 | 捕获解压错误，返回校验失败 |
| 离线操作时间只到秒，同一秒内按随机编号排序，签退可能排在签到前 | 浏览器断网验收 | 增加客户端序号，按时间和序号排序，补回归测试 |
| 前端“当前时间”取浏览器时区，和服务端东八区不一致时，离线操作时间和日期默认值出错 | 浏览器验收截图 | 前端统一以服务器时间为准 |
| Service Worker 只缓存访问过的页面，没打开过的页面断网打不开 | 代码检查 | 构建时把全部产物写入预缓存清单 |
| 未受理的工单进入派单页时页面空白 | 浏览器验收截图 | 增加状态提示 |

## 没有覆盖的部分

- 没有做压力测试。并发只验证了派单冲突场景。
- 短信是模拟网关，没有接入真实运营商。
- 可穿戴数据由脚本模拟，没有使用真实设备。
- 手机上的真实定位、语音输入和朗读没有实测。验收使用桌面 Edge 无头模式，定位按钮只验证了模拟路径。
- 只在 SQLite 上运行过。代码没有使用 SQLite 专有语法（审计触发器和备份除外），但没有在 PostgreSQL 上验证。
- 大模型接入只测了调用边界和失败回退（用桩函数），没有连接真实模型。
- 容器只验证了启动、登录和业务接口，健康检查在观察时还处于 starting 状态，容器内没有再跑完整流程。
